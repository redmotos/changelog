## Nuevo

<ul class="changes">
  <ChangeItem title="Sincronización automática de imágenes de productos">
    Las imágenes de productos que se suben al almacenamiento en la nube ahora se enlazan automáticamente al producto correspondiente, sin necesidad de cargarlas manualmente desde Backoffice.
  </ChangeItem>
</ul>

## Correcciones

<ul class="changes">
  <ChangeItem title="Confirmación explícita para canjear enlaces de invitación">
    Los enlaces de invitación para clientes ya no se canjean automáticamente al abrirlos: ahora muestran una pantalla de bienvenida y piden confirmar antes de iniciar sesión, para que previsualizaciones automáticas de aplicaciones de mensajería no invaliden el enlace antes de que el cliente lo use. Si el enlace ya fue usado o venció, se muestra un mensaje claro con la opción de pedir uno nuevo.

    <ReleaseGallery images={[inviteScreen, inviteExpiredScreen]} alt="Pantallas de invitación de cliente: bienvenida y enlace vencido" />

  </ChangeItem>
</ul>
